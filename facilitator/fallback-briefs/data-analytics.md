Attack any number that has no workflow behind it — MORENO-AGENT's $140M in particular. That limit is technical, not tactical.

## Red lines
Never commit to a target above $80M. Never agree to exceed 80% capability in year one. Never absorb the cost of the shared data layer inside our own allocation — if the enterprise wants it, the enterprise funds it.

If we are losing, fall back to the technical argument — nothing works without validated data — and remind the room that we are the only group that can build the layer.
